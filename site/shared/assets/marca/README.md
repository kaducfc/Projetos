# Marca do Rift Arcade

| Arquivo | Uso |
|---|---|
| `mascote.png` (120×120) | Original: só o mascote. Rodapé do site e logo da tela de login do Google. |
| `logo-fundo-claro.png` (281×108) | Original: mascote + "RIFT ARCADE" com "RIFT" escuro. Para fundos claros. |
| `logo-fundo-escuro.png` | Mesma logo com "RIFT" claro. Usada na barra do site, no topo da página inicial e nos e-mails. |
| `favicon-32.png`, `favicon-48.png` | Ícone da aba do navegador. |
| `apple-touch-icon.png` (180×180) | Ícone ao salvar o site na tela inicial do celular. |
| `icone-512.png` | Ícone grande (redes sociais, loja de apps, perfis). |
| `compartilhar.jpg` (1200×630) | Imagem que aparece ao compartilhar o link (WhatsApp, Discord, X…). |

Os derivados foram gerados a partir dos dois originais. Se a logo mudar, troque
os originais e peça para gerar os derivados de novo. Versões originais em
resolução maior (ex.: 4× o tamanho atual) deixam a logo mais nítida em telas
de alta densidade.
