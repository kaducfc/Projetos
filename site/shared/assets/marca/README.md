# Marca do Rift Arcade

Os originais em alta resolução ficam em `originais/` (`logo.png` 1555×688 e
`mascote.png` 651×688, fundo transparente). Tudo o mais é gerado a partir deles.

| Arquivo | Uso |
|---|---|
| `logo-fundo-escuro.png` (900 px) | Logo com "RIFT" em tom claro. Topo da página inicial. |
| `logo-barra.png` (300 px) | A mesma, leve: barra do site e cabeçalho dos e-mails. |
| `logo-fundo-claro.png` (900 px) | Logo original, "RIFT" escuro. Para fundos claros. |
| `mascote.png` (512×512) | Mascote recortado e centralizado. |
| `mascote-120.png` (120×120) | Rodapé do site e logo da tela de login do Google. |
| `favicon-32.png`, `favicon-48.png` | Ícone da aba do navegador. |
| `apple-touch-icon.png` (180×180) | Ícone ao salvar o site na tela inicial do celular. |
| `icone-512.png` | Ícone grande (perfis em redes sociais etc.). |
| `compartilhar.jpg` (1200×630) | Imagem que aparece ao compartilhar o link (WhatsApp, Discord, X…). |

Se a logo mudar, troque os arquivos em `originais/` e gere os derivados de novo.
