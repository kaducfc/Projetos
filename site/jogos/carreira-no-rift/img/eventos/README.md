# Imagens das decisões (eventos)

Uma imagem por decisão do Carreira no Rift. Ela aparece como banner no topo
do card da decisão, no lugar do fundo com emoji. Decisão sem imagem continua
com o fundo atual.

- **Formato:** PNG ou JPG, **1200×520 px** (horizontal, bem largo).
- **Foco no centro:** no celular as laterais são cortadas, e a parte de baixo
  escurece para o fundo do card.
- **Nome do arquivo:** exatamente o da coluna "Arquivo" (ex.:
  `soloq_madrugada.png`).
- Depois de enviadas, as imagens são convertidas para **JPG 1200×520**
  (`<arquivo>.jpg`, ~90 KB cada) — é esse arquivo que o jogo usa.
